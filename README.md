# Age and ISS stage after autologous transplantation

[View the reproducible supplement](https://aportugu.github.io/bmt-age-iss-supplement/).

This report presents the analysis, tables, and figure for the age-by-ISS-stage comparison among selected recipients of upfront autologous transplantation for multiple myeloma in the public CIBMTR P-5544/MM19-01 cohort. Expandable code is included in the report.

[Access the CIBMTR public dataset catalog](https://cibmtr.org/CIBMTR/Resources/Publicly-Available-Datasets).
